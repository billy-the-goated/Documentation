Suggested order

  1. Arch with archinstall and i3: get a working system first.
  2. Jellyfin: the drive setup in Step 2 is reused by anything else that needs storage.
  3. Minecraft server: it can run on the same machine, since it uses a different port (25565) from Jellyfin (8096).

Before you forward any ports

Both server guides end with port forwarding. Check for CGNAT first (it's in the Jellyfin guide, Step 3.6), because if your ISP shares your public IP, port forwarding can't work and you'll want Tailscale instead.

Keep all four files in the same folder so the links work. Each guide also works on its own and offline.
