Minecraft Java Server on Arch Linux

Set up a vanilla Java Edition server, run it in the background, and let friends join from outside your network.

Step 1: Install Java

The Java version you need depends on the Minecraft version, and Mojang changes it from time to time. At the time of writing:

Minecraft versionJava needed
1.20.5 to 1.21.xJava 21
26.1 and newer (the new year-based versions)Java 25

Newer Java generally runs older Minecraft versions fine, so installing Java 25 covers both. Check the release notes for your version if you're unsure.

Install it

A server doesn't need a graphical Java, so install the headless package:

sudo pacman -Syu
sudo pacman -S jre25-openjdk-headless

If that package name isn't found, list what's available and pick the right one:

pacman -Ss openjdk | grep headless

Check it

java -version

It should report version 25 (or 21). If you have several Java versions installed, see which is active and switch:

archlinux-java status
sudo archlinux-java set java-25-openjdk

Step 2: Make the server folder and get the jar

Keep everything in one folder, since the world, config and logs all live next to the jar.

mkdir -p ~/minecraft-server
cd ~/minecraft-server

Download the server jar

The official jar comes from Mojang, and the link changes with every version, so copy it from the website:

  1. Open https://www.minecraft.net/en-us/download/server in a browser.
  2. Right-click the minecraft_server.x.x.x.jar link and choose Copy link address.
  3. Download it on the server, pasting your link between the quotes:
wget -O server.jar "PASTE_THE_LINK_HERE"

Naming it server.jar keeps your start script the same when you update later. Confirm it downloaded:

ls -lh server.jar

The file should be around 50 MB. If it's tiny, the link was wrong, so copy it again.

Step 3: Accept the EULA and run it for the first time

First run (this one fails on purpose)

java -Xms2G -Xmx4G -jar server.jar nogui

It stops straight away and creates eula.txt. -Xms is the starting RAM and -Xmx is the maximum. nogui skips the graphical window.

Accept the EULA

By setting it to true you agree to Mojang's EULA (https://aka.ms/MinecraftEULA). Read it first.

sed -i 's/eula=false/eula=true/' eula.txt
cat eula.txt

Run it again

java -Xms2G -Xmx4G -jar server.jar nogui

The first full start generates the world and takes a minute or two. When you see a line ending in Done (x.xxxs)! For help, type "help", the server is up.

Join it locally

In Minecraft Java Edition (same version as the server), go to Multiplayer → Add Server and enter:

  • localhost if you play on the server itself.
  • The server's local IP (like 192.168.1.50) from another device on your network. Find it with ip -4 a.

Server console commands

Type these in the server's terminal (no slash needed):

op YourName       # make yourself an operator
list              # show online players
save-all          # force a world save
stop              # shut down cleanly

Always use stop instead of closing the terminal or pressing Ctrl+C, or you risk losing recent progress.

Step 4: Configure the server

Stop the server first, then edit the settings file:

nano ~/minecraft-server/server.properties
SettingWhat it does
server-port=25565The port the server listens on. Keep the default unless you have a reason.
online-mode=trueChecks that players own the game. Keep this on.
white-list=trueOnly listed players can join. Add people with whitelist add Name in the console.
max-players=10Player limit.
motd=My serverThe text shown in the server list.
difficulty=normalpeaceful, easy, normal or hard.
gamemode=survivalThe default mode for new players.
view-distance=10Chunks sent to each player. Lower it (6 to 8) if the server lags.
simulation-distance=8How far from players the world stays active. Also lowers lag.

Don't set online-mode=false on a server open to the internet. Anyone could join as any username, including yours.

Changes only apply after a restart.

Step 5: Start script and running in the background

Create a start script

nano ~/minecraft-server/start.sh
#!/bin/bash
cd "$(dirname "$0")"
java -Xms4G -Xmx4G -jar server.jar nogui
chmod +x ~/minecraft-server/start.sh

Setting -Xms and -Xmx to the same value avoids RAM resizing while playing. Never give it more RAM than the machine has free, or the system will start swapping. 4 GB is a good start for a small group.

Keep it running with tmux

If you start the server in a normal terminal, closing it stops the server. tmux keeps it alive in the background:

sudo pacman -S tmux
tmux new -s minecraft
~/minecraft-server/start.sh
  • Detach (leave it running): press Ctrl+B, release, then press D.
  • Reattach later to use the console: tmux attach -t minecraft
  • Stop it properly: reattach, then type stop.

Step 6: Port forwarding

Minecraft Java Edition uses TCP 25565. UDP isn't needed.

1. Find the server's local IP

ip -4 a

Find your active interface and its inet line, such as inet 192.168.1.50/24. The local IP is 192.168.1.50. Ignore 127.0.0.1.

2. Make the local IP permanent

If the server's IP changes after a reboot, the forward points at nothing. In the router settings, find DHCP Reservation, Static DHCP or Address Reservation, pick your server (or enter its MAC address from ip link), and assign it a fixed IP. Ethernet is much better than Wi-Fi for a server.

3. Open the router

ip route | grep default

If it shows default via 192.168.1.1, open http://192.168.1.1 in a browser and log in. The password is often on a sticker on the router.

4. Create the port forward

Look for Port Forwarding, NAT, Virtual Server or Applications & Gaming, then add a rule:

FieldValue
NameMinecraft
ProtocolTCP
External / WAN port25565
Internal / LAN port25565
Internal IPYour server's local IP (for example 192.168.1.50)
EnabledYes

Save and apply. Some routers need a reboot.

5. Server firewall

If you use ufw (otherwise skip):

sudo ufw allow 25565/tcp
sudo ufw status

6. Find your public IP and check for CGNAT

curl ifconfig.me

Compare the result with the WAN / Internet IP on your router's status page.

If they differ, or the router shows an address starting 100.64. to 100.127., 10. or 192.168., your ISP uses CGNAT and port forwarding cannot work. Ask the ISP for a public IP, or use a tunnel such as Tailscale (everyone who joins needs it installed).

7. Test it

Ask a friend outside your network to add your public IP as a server in Minecraft. Because 25565 is the default port, they don't need to type it. Testing from inside your own network often fails even when the setup is correct, so use the local IP from home. An online "Minecraft server status" checker also works.

When your public IP changes

Most home connections have a dynamic IP, so the address you gave friends can stop working. A Dynamic DNS service such as DuckDNS (free) gives you a fixed name like myserver.duckdns.org that follows your IP.

Running Jellyfin on the same machine is fine. They use different ports (8096 and 25565), each with its own forward.

Step 7: Backups and updates

Back up the world

Stop the server first (stop in the console), then:

tar -czf ~/mc-backup-$(date +%F).tar.gz -C ~ minecraft-server

Copy the archive to another drive, since a backup on the same disk won't survive a disk failure.

Update the server

  1. Run stop and make a backup as above.
  2. Check which Java version the new Minecraft version needs and install it if it's different.
  3. Download the new jar over the old one: 
    cd ~/minecraft-server
wget -O server.jar "PASTE_THE_NEW_LINK_HERE"
  4. Start the server. It upgrades the world automatically.

Worlds can't be downgraded. If an update goes wrong, restore from your backup.
